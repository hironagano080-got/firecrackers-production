# Saturday's Mine Hooks 照明の設計

## 方針（2026-11-26 Hiro決定）

- **前半 ①〜④（0.00〜9.64）**：今の「全灯」照明のまま。暖色と白で、ステージ全体が均一に明るい
- **後半 ⑤〜⑧（9.64〜20.00）**：9.64秒のクラッシュでカットが⑤に変わった瞬間から「演奏照明」。暗い中を色付きの光が走る
- 切り替えの演出：サビ後半の頭で、照明でも一段ギアが上がる
- 前後半の差に違和感が出た場合は、①〜④を演奏照明で作り直す

## 演奏照明の決まり（⑤〜⑧で共通。画像指示文とSeedanceプロンプトの両方に入れる）

```
照明はライブ演奏中のもの。客席はほぼ真っ暗。会場にはうっすらスモークが漂い、光の筋が見える。
ステージ上の鉄骨から、赤、青、緑、マゼンタのスポットライトが斜め上や真横、後ろなど様々な角度から人物に当たる。
メンバーは後ろからの逆光で髪と肩の輪郭が光り、顔には色の付いた光が半分だけ当たる。正面からの白い光は弱い。
ステージ全体を均一に照らす暖色の全灯はなし。
```

動画（Seedance）ではさらに次を足す：

```
スポットライトの向きは固定で、動かない。約20灯のうち半分の10灯ずつが拍ごとに交互に点いたり消えたりし、点くたびに色が変わる。小節の終わりには全灯がパパッと明滅する。クラッシュの瞬間に白いストロボが一瞬光る。
```

- 2026-11-26 Hiro指摘：ライブハウスの照明は左右に振れない。色が変わる・明滅するだけ（例：20灯なら10-10で切り替わる）
