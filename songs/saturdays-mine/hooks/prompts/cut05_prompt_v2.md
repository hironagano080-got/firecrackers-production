## プロンプト（コピー用）

```
実写のライブ映像。暗いライブハウスの客席の上空を、FPVドローンがステージへ向かって飛んでいく5秒のワンカット。
@画像1 の構図で始まり、4.5秒で @画像2 の構図に到達して止まる。
カメラの軌道と速さは @動画1 と同じにする：最初に一気に加速し、観客の頭上すれすれを右、左、右、左と大きく蛇行しながら前進する。曲がるたびに機体ごと大きく傾き（最大で約25度）、画面の水平線がはっきり斜めになる。最後にステージの手前で減速し、水平に戻って止まる。@動画1 は動きだけの参考で、見た目や色は参考にしない。

観客：ぎっしりの観客が @音声1 のビートに合わせて跳ね、腕を突き上げている。観客は暗いシルエットで、輪郭だけが光で縁取られる。カメラは観客の頭上を越えていき、人にはぶつからない。

バンド：立ち位置は @画像1 と @画像2 のまま。全員が激しく演奏している。中央のボーカルは @画像2 の人物そのもので、マイクに向かって叫ぶように歌う。終盤の [2.4-4.5s] Jamie lip syncs: "Nobody cares what I choose"。左奥のドラマーは満面の笑顔で頭を振りながら叩く。

照明：ライブ演奏中の照明。客席はほぼ真っ暗。会場にはスモークが漂い、光の筋が見える。ステージ上と客席上の鉄骨に約20灯のスポットライトが並び、向きは固定で動かない。半分の10灯ずつが @音声1 の拍ごとに交互に点いたり消えたりし、点くたびに赤、青、緑、マゼンタと色が変わる。小節の終わりには全灯がパパッと明滅する。何本かの光の筋は観客の頭上を斜めに横切る。メンバーは逆光で髪と肩の輪郭が光る。0秒の瞬間に白いストロボが一瞬光る。

禁止：激しい回転、光の筋が左右に振れる動き、人や機材を突き抜ける動き、カット割り、人物の入れ替わりや顔・衣装の変化、ステージの形や広さの変化、暖色の全灯、文字や字幕、新しい音楽の生成。
```

## うまくいかない時
- 傾きが出ない → 「曲がるたびに機体ごと大きく傾く」を冒頭の軌道の文に移し、「FPVレースのような旋回」を足す
- 傾きすぎて酔う、または回転してしまう → 「最大で約25度」を「最大で約15度」に。禁止に「360度の回転」を足す
- 照明が振れる → 照明の文の先頭に「スポットライトは首を振らず、点滅と色の切り替えだけ」を置く
- @動画1 の簡易な見た目が混ざる → 「@動画1 はカメラの動きだけの参考」をプロンプトの先頭に移す
- 終点で止まらずステージに突っ込む → 「4.5秒で完全に静止し、残りはその構図を保つ」を足す
